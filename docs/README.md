# 文档目录

本目录集中保存项目说明、设计文档和阶段性报告。

## 项目文档

- `project/`：架构、规范、项目概览、交接说明与访问说明。

## 阶段报告

- `reports/diagnosis/`：诊断与设计工作台相关报告。
- `reports/gold-evidence/`：Gold 标注、证据、原子主张与验收报告。
- `reports/literature/`：文献发现、分类、检索与验证报告。
- `reports/paper-extraction/`：PDF 解析与论文实验抽取报告。
- `reports/skill07/`：Skill07 设计、测试和验收报告。
- `reports/skill08/`：Skill08 设计、测试和验收报告。
- `reports/release/`：版本收口、迁移与发布审计报告。

根目录仅保留项目入口和运行所需配置。生成的数据、日志与截图分别放在 `artifacts/data/`、`artifacts/logs/` 和 `artifacts/screenshots/`。
