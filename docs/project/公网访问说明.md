# WAVE Agent 公网访问

## 日常使用

1. 双击 `启动网站.cmd`，等待本地网站启动完成。
2. 双击 `启动公网访问.cmd`。
3. 第二个窗口会显示一个 `https://...trycloudflare.com` 地址，把它发给可信的访问者。
4. 保持网站窗口和公网访问窗口都处于运行状态。关闭公网访问窗口后，外部地址即失效。

生成的地址也会写入 `.public-tunnel/public-url.txt`。首次运行会从 Cloudflare 官方 GitHub Release 下载 `cloudflared.exe`，以后直接复用。

## 注意事项

- 这是 Cloudflare Quick Tunnel，免费且不要求账号，但每次重新启动通常会生成一个新地址。
- Quick Tunnel 适合临时分享、演示和测试，不适合长期生产部署。
- 这个地址本身没有密码保护。访问者可以使用页面暴露的 Agent 能力，并可能消耗后端配置的模型额度，因此只应分享给可信的人。
- 无需开放路由器端口；本地服务仍只监听 `127.0.0.1`。

## 使用不同的本地端口

默认公开 `http://127.0.0.1:8642`。如果后端改到了其他端口，可在 PowerShell 中运行：

```powershell
.\start-public-tunnel.ps1 -Origin http://127.0.0.1:8651
```

## 固定网址

固定网址需要一个 Cloudflare 账号和一个已接入 Cloudflare 的自有域名。创建 Named Tunnel、配置公开主机名并取得 Tunnel Token 后，可把当前快速隧道脚本切换为固定隧道模式。不要把 Tunnel Token 写入 Git 或发给别人。
