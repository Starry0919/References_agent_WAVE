# Literature Search Request v3

Contract `literature-search-request/3.0` represents organism/species/lineage/aliases/exclusions, canonical and related products, objective/direction/metrics, engineering intent, publication and design preferences, time scope, search mode, diversity/fulltext policy, citation modes, and explicit budgets.

The deterministic parser supports general unknown hosts/products without silently substituting K-12 or tryptophan. Supported modes are BALANCED, DIRECT_ENGINEERING, REVIEW_SYNTHESIS, MECHANISTIC, RECENT, CLASSIC, and FULLTEXT_VERIFIED. Unrecognized scientific entities remain `UNKNOWN` for later structured resolution.
