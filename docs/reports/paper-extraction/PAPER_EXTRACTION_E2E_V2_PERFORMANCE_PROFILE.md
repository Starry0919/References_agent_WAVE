# Benchmark V2 performance profile

The evaluator emits output size, total claims, median and p95 claims per experiment, largest experiment, duplicate IDs, verification/E2E runtime and annotation payload size where available. Warnings flag claim explosion and duplicates; valid science is not truncated by arbitrary caps. Current scoped V3 unit tests complete in under one second; real-model extraction latency is environment/model dependent and was not re-measured here.
