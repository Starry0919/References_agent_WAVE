# Synthetic Biology Design Studio Frontend Phase 2
# Backend Integration


# 1. Objective


Connect the existing frontend UI with Synthetic Biology Agent V2 backend.


After this phase:

The user should be able to:

1. Enter a biological engineering problem.

Example:

"Improve L-tryptophan production in E. coli K-12"


2. Submit the task.


3. Backend executes:

Phase Workflow:

- Problem Definition
- Pathway Analysis
- Bottleneck Diagnosis
- Engineering Design
- Evaluator
- Validation
- Report


4. Frontend displays the complete design process.



# 2. Important Constraints


Do NOT:

- modify backend reasoning logic
- change knowledge base
- implement Three.js
- implement advanced biological visualization


Only focus on:

API communication

+
data visualization.

# 5. Data Types

Create:

```
src/types/

synbio.ts

```

Define interfaces:

## Objective

```typescript
interface Objective {

host:string;

product:string;

substrate:string;

goal:string;

}

```

## Pathway

```typescript
interface PathwayAnalysis {

pathway:string[];

precursors:string[];

competingPathways:string[];

}

```

## Engineering Action

```typescript
interface EngineeringAction {


gene:string;


modification:string;


effect:string;


evidenceType:string;


risk:string;


priority:string;


}

```

## Evidence

```typescript
interface Evidence {

}

```

## Evaluation

```typescript
interface Evaluation {
```

