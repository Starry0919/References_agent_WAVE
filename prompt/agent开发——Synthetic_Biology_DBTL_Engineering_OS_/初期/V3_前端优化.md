# Synthetic Biology Design Studio Frontend V1


# 1. Product Vision


Build a professional scientific AI interface for Synthetic Biology Agent V2.


Product name:

Synthetic Biology Design Studio


Positioning:

An AI-powered virtual laboratory for microbial metabolic engineering design.



The interface should feel like:

- AI Research Laboratory
- Virtual Cell Engineering Platform
- Synthetic Biology Design Workspace



It should NOT look like:

- ChatGPT clone
- Generic dashboard
- Simple form website



# 2. Core User Experience


The user workflow:


User enters:


"Improve L-tryptophan production in E. coli K-12"


↓

Agent starts design workflow


↓

Frontend visualizes:


Phase Workflow

↓

Pathway Analysis

↓

Bottleneck Diagnosis

↓

Engineering Design

↓

Evaluator Review

↓

Validation Plan

↓

Final Report



The user should understand:

WHY the Agent proposes a modification.
