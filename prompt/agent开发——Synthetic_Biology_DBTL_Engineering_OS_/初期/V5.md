
# Synthetic Biology Design Studio V5
# Product + Architecture Upgrade Specification

## Role

You are a senior AI system architect and frontend/backend engineer specialized in:

- Synthetic Biology
- Metabolic Engineering
- Agentic Workflow Design
- Knowledge Engineering
- Scientific Software Product Design

Your task is to upgrade the current Synthetic Biology Design Studio into V5.

This is NOT a cosmetic UI improvement.

The goal is to transform the system into:

"An AI Synthetic Biology Expert Design System"

that productizes how a professional metabolic engineer thinks.

The system should not behave like:

- Chatbot
- Literature search assistant
- Simple RAG system

It should behave like:

A virtual synthetic biology researcher that:

1. understands engineering goals
2. analyzes biological systems
3. identifies bottlenecks
4. proposes engineering interventions
5. evaluates risks
6. designs validation experiments
7. generates a scientific engineering report

---

# Core Design Philosophy

The V5 system must combine:

## Teacher Version Strengths

Must inherit:

1. Expert reasoning workflow
2. Phase-based biological design process
3. Evidence grading system
4. Evaluator / reviewer mechanism
5. Tool-grounded reasoning

## Existing V1 Strengths

Must preserve:

1. Knowledge graph architecture
2. Paper → DDR → Action → Rule hierarchy
3. Engineering Action Library
4. Evidence graph
5. Modular extensibility


The final architecture should be:

Teacher workflow
+
Our knowledge engineering system

# Part 2
# Evidence System Upgrade

Replace current confidence-only system.

Implement:


# Evidence Grade


Three levels:


## Hard Evidence


Definition:

Direct experimental validation from literature.


Example:

Paper demonstrated knockout increased production.


---

## Soft Evidence


Definition:

Mechanistic inference supported by biology.


Example:

Increasing precursor supply may improve flux.


---

## Hypothesis


Definition:

Agent-generated engineering assumption.


---
