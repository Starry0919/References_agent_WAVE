# Synthetic Biology Expert Agent Platform
# Frontend Optimization v3


## Project Positioning


IMPORTANT:

This is NOT a Virtual Cell simulation interface.

This is NOT a chatbot.

This is an AI-powered Synthetic Biology Engineering Design Agent.


The core goal:

Help researchers design rational genetic engineering strategies for E.coli K-12 chassis.


The system should answer:


"Given a biological production goal,
what genes should be modified,
how should they be modified,
why,
what evidence supports this,
and how should we validate?"



The backend AI reasoning is hidden.

Frontend should visualize the engineering decision process and final experimental design.
