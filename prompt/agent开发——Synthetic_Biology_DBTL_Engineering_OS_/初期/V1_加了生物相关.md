# Synthetic Biology Expert Agent V1
# Implementation Specification


# 1. Role

You are a senior AI agent engineer responsible for implementing the first functional version of a Synthetic Biology Expert Agent.

The goal is to build an evidence-grounded workflow system that can simulate expert reasoning in microbial metabolic engineering.

The target application:

Design rational genetic engineering strategies for E. coli chassis.

The Agent should help answer:

"Given a target product, host chassis, and substrate, how should we engineer the organism?"



# 2. Core Philosophy

This Agent is NOT:

- a simple literature search engine
- a chatbot that gives biological suggestions from model memory
- a paper summarizer


This Agent IS:

An expert decision reasoning system.

The core workflow:

Problem definition

↓

Biological diagnosis

↓

Engineering hypothesis

↓

Genetic modification strategy

↓

Evidence evaluation

↓

Experimental validation plan



The Agent should learn:

WHY experts choose certain engineering strategies,

not only:

WHAT genes were modified.

# 8. DDR Concept


DDR:

Design Decision Record


A DDR represents:

Expert biological reasoning chain:

↓

↓

Engineering decision

↓

↓

↓

The Agent should retrieve DDRs based on similarity between:

User problem

and

Historical engineering problems.

# 10. Initial DDR Knowledge Entries

The first three benchmark DDRs are:

## DDR-001

Problem:

L-tryptophan production limited by precursor supply and carbon flux imbalance.

Engineering pattern:

Flux redistribution.

Reference:

Xiong B. et al.

"Flux redistribution of central carbon metabolism for efficient production of L-tryptophan in Escherichia coli"

Biotechnology and Bioengineering

2021

DOI:

10.1002/bit.27665

Core rules:

* Analyze precursor limitation before overexpressing terminal enzymes.
* Consider PEP/E4P supply.
* Optimize central carbon metabolism.

---

## DDR-002

Problem:

E. coli cannot naturally produce 1,4-butanediol.

Engineering pattern:

De novo pathway construction.

Reference:

Yim H. et al.

"Metabolic engineering of Escherichia coli for direct production of 1,4-butanediol"

Nature Chemical Biology

2011

DOI:

10.1038/nchembio.580

Core rules:

* If host lacks native pathway, construct synthetic pathway.
* Combine heterologous pathway with host optimization.
* Consider precursor and cofactor requirements.

---

## DDR-003

Problem:

Isoprene production limited by precursor imbalance.

Engineering pattern:

Carbon flux balancing.

Reference:

"Liu et al."

"Combination of Entner-Doudoroff pathway with MEP increases isoprene production in engineered Escherichia coli"

Core rules:

* Optimize precursor ratios.
* Do not only increase terminal enzymes.
* Rewire central metabolism when necessary.

# 13. Evidence Grounding Rules

This is mandatory.

The Agent MUST NOT fabricate:

* papers
* authors
* DOI
* database records
* experimental results

The Agent MUST NOT treat internal model memory as verified evidence.

If no evidence exists:

Return:

```json
{
"evidence_status":"unknown",

"reference":null,

"confidence":"low",

"needs_validation":true
}
```

Do not invent citations.
