6. 降级与已知限制(诚实边界)
反事实模型覆盖窄:仅 pykF/ptsG/ppc 三个基因映射到 cobrapy 自带 e_coli_core 教科书模型的真实反应,其余目标(如 trpE、xfpk)超出该小模型域,如实返回 out_of_domain/not_computed。vEcoli/动力学模型未接入,如实返回 unavailable。
客观向量以定性序数为主:titer/yield 等主指标 magnitude 默认 not_computed(标注 evidence_tier=expert_or_llm_judgment),仅当 GEM 反事实命中真实基因映射时才写入真实计算值 —— 遵守"不得伪造没有量纲和校准的伪精确分数"。
无前端 UI:未新建/修改任何前端页面。web/index.html 是既有聊天会话界面,Problem 2/3 本身也仅以 additive REST API 形式存在、无专属仪表盘,本次遵循同一先例,优先保证后端闭环、API 与测试。
策略生成为确定性规则式(非实时 LLM 调用),与 hypothesis_generator.py/strategy_router.py 的既有先例一致:可复现、可单测、且不会让 LLM 自评混入证据链。
