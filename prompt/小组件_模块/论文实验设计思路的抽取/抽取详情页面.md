# Claude Code Implementation Prompt

## Task: Implement Literature Evidence Detail Page with Agent Reasoning Trace and Extracted Experimental Design

### Background

The system currently contains a module:

**论文实验设计抽取 (Paper Experimental Design Extraction)**

Workflow:

```
User selects/searches paper
        ↓
Paper retrieval
        ↓
DOI verification
        ↓
PDF download
        ↓
PDF → Markdown
        ↓
Literature cleaning
        ↓
Experimental design extraction
        ↓
Evidence binding
        ↓
Structured JSON output
        ↓
Saved into 文献证据 (Literature Evidence)
```

After extraction is completed, the generated record must be stored in:

```
文献证据 (Literature Evidence)
```

Each literature evidence card already has:

```
Paper title
Authors
Journal
Year
DOI
Extraction status
Evidence quality
```

A new interaction must be implemented:

```
文献证据列表
        |
        | click "详情"
        ↓
Literature Evidence Detail Page
```

Also:

When:

```
论文实验设计抽取 workflow
```

finishes extracting one paper completely,

the system should automatically navigate to this same detail page.

---

# Core Product Requirement

This page is NOT a normal literature summary page.

Do NOT simply display:

```
Paper information

Abstract

Extracted experimental design

Conclusion
```

This is insufficient.

The page should demonstrate:

> How the Agent thinks and how the experimental design was reconstructed.

The page should be an:

```
Agent Reasoning Trace
        +
Experimental Design Reconstruction
        +
Evidence Provenance
```

interface.
