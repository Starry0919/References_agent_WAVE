# 三、研究目标与假设

## 研究目标

构建一个覆盖全局调控网络的高分辨率饱和突变文库，通过表型选择和高通量测序将调控蛋白突变映射到复杂表型，并验证该文库能否在单轮选择中发现提高抑制物耐受性或目标化合物产量的突变。

证据：

- 摘要：设计、构建并映射包含 82 个调控因子、110,120 个特定突变的调控网络文库。
- Introduction 末段：使用 CREATE 构建调控因子活性位点饱和突变文库，并筛选工业相关复杂性状。

> 对多个全局调控蛋白的功能位点进行高密度、可追踪突变，可以重编程细胞代谢，并在不同选择压力下富集出改善复杂表型的调控突变。

状态：`inferred`。

# 四、实验设计总体结构

## 阶段 A：调控网络与靶点设计

1. 从 NCBI、EcoCyc、RegulonDB、UniProt、PDB、Pfam 和既往文献整理调控因子及功能位点。
2. 选择 82 个调控因子，覆盖或关联约 4000 个基因。
3. 对 DNA/配体结合区域、蛋白互作界面和预测结构域设计饱和突变。
4. 形成 110,120 个预设计突变，并通过编辑盒条形码追踪。

关键参数：

- PDB 结构位点：围绕结合区和二聚化界面，小于 5 Å。
- Pfam 预测位点：后验概率大于 90%。

## 阶段 B：质粒文库与 MG1655 基因组编辑文库构建

1. 扩增合成寡核苷酸池与质粒骨架。
2. 使用 CPEC 组装质粒文库。
3. 将组装产物转入 `E. cloni 10G ELITE` 扩增质粒文库。
4. 将文库编辑质粒转入携带 pSIM5 和 pX2-Cas9 的 MG1655。
5. 在 OD600 0.5–0.6 时，以 42 °C、15 min 诱导 pSIM5。
6. 电转后使用 SOB 恢复 2 h，再进入含抗生素的 LB。
7. 每个子文库随机测序 50 个克隆，评估编辑效率和多样性。

主要质量指标：

- 编辑效率：30%–85%。
- 突变多样性：30%–74%。
- 文库分成四个子文库；每个子文库检查 50 个随机克隆。

## 阶段 C：多表型耐受性选择

分别对每个子文库施加：

| 表型 | 选择压力 |
|---|---:|
| 糠醛耐受 | 2 g/L furfural |
| 苯乙烯耐受 | 300 mg/L styrene |
| 乙酸耐受 | 30 g/L acetate |
| 异丙醇耐受 | 30 g/L isopropanol |
| 异丁醇耐受 | 8 g/L isobutanol |

共同流程：

1. 初始接种 OD600 = 0.1。
2. 根据生长速率在 48–96 h 内进行两次连续稀释选择。
3. 提取选择后群体的质粒。
4. 测序条形码—编辑盒区域。
5. 比较选择前后变体频率并计算富集分数。

自变量：

- 抑制物种类与浓度；
- 调控因子突变。

主要因变量：

- 生长/OD600；
- 变体选择前后频率与富集分数；
- 重构突变株的耐受表型。

基准对照：

- nontargeting control；
- wild-type/background strain comparison，在原文明确对应时使用。

禁止把所有 `wild-type` 字样自动映射为单一额外实验组；必须绑定到具体图、选择条件和菌株背景。

## 阶段 D：条形码测序与富集分析

1. Illumina paired-end reads 按 Golay barcode 分选。
2. 合并 reads，并与预设计编辑盒数据库匹配。
3. 初始匹配 identity threshold 为 90%，最终设计归属 cutoff 为 99.5%。
4. 每个生物学重复计算选择后/选择前频率比的富集分数。
5. 以 read count 加权合并两个生物学重复。
6. 使用同义突变的富集分布作为背景，bootstrap 重采样 20,000 次得到 95% CI。

统计判据：

- 两个生物学重复用于富集分析。
- 论文用同义突变分布估计背景，并以约 `μ ± 2σ` 判定显著富集；报告为近似 `P ≤ 0.05`。

## 阶段 E：候选突变重构与表型验证

1. 将候选 editing cassette 单独订购并转入相应目标宿主。
2. 在与 pooled library 相同的条件下重复表型测试。
3. 以 nontargeting control 作为主要基准。
4. 对部分候选突变执行 RNA-seq、qPCR、ATP 测定或生产发酵，验证机制和产量。

代表性结果包括：

- 多个调控因子突变提高糠醛、苯乙烯、乙酸、异丙醇或异丁醇耐受性。
- `FliA_R94K` 与醇胁迫耐受和广泛转录变化相关。
- `OmpR_S181K` 在异丁醇生产验证中达到约 10.6 g/L，约为 nontargeting control 的 1.4 倍。

这些结果属于论文报告，不能推广成所有调控突变均有效。

## 阶段 F：异丁醇生产选择与发酵验证

1. 将调控网络文库转入 `IB500C ΔadhE`。
2. 使用带 `tetA-gfp` 的 `pSelect-1`，把异丁醇感应与生长/GFP 读出耦合。
3. 在 96 孔板中进行生产表型选择。
4. 测序富集突变，并在生产背景中逐一重构。
5. 以摇瓶或 fed-batch 发酵测量异丁醇产量。

发酵条件必须按产物分开：

- 异丙醇：250 mL 摇瓶、25 mL SD-8、220 rpm、37 °C、2% glucose。
- 异丁醇批次：M9、37 °C、24 或 48 h；正文给出高糖与酵母提取物配方。
- 异丁醇 fed-batch：250 mL 摇瓶、50 mL 培养液、30 °C、pH 约 7.0，按残余葡萄糖补料。

禁止把这些条件合并成单一“培养条件”数组。

# 六、重复、对照和统计语义

必须把不同实验的重复分开：

- 文库编辑效率：四个子文库各随机检查 50 个克隆，不等于生物学重复数。
- 富集分析：正文 Methods 明确两个 biological replicates。
- qPCR：triplicates；正文未在该句中说明是技术还是生物学重复，不应擅自归类。
- 部分图的发酵验证：图注明确 `n = 3` 或 `three biological replicates` 时，可绑定到对应实验。

对照包括：

- nontargeting editing control；
- 具体实验中的 wild-type/background strain；
- 选择前 population 作为频率基线。

不同对照不得跨实验合并成一个无条件的 `control`。

## 方法学限制

- 文库编辑效率和多样性在子文库间差异较大。

- 不同表型的富集突变具有条件依赖性，不能脱离选择压力解释。
