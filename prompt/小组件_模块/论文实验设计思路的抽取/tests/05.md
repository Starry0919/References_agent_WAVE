# 第五篇论文 Skill 回归测试

## 测试对象

- 论文：*Refactored genetic codes enable bidirectional genetic isolation*
- DOI：10.1126/science.add8943
- 文件：`04.pdf`
- 期刊与年份：*Science*，2022
- PDF：正文 8 页，另含 1 页文章信息
- 测试目标：验证 `WT` 多义消歧、菌株家族与具体宿主隔离、水平基因转移方向性、逃逸机制、16 种遗传密码体系、正交/互正交 HGT、code locking、批量验证矩阵、强结论范围和补充材料硬门控。

## 总体结论

**PASS WITH MODERATE REVIEW：论文的实验设计主线和关键对象可以可靠抽取，但完整的菌株/质粒构建、五套互正交 HGT 系统、重复数、统计学及检测下限依赖 Supplementary Materials。**

本文是原创实验研究。作者以 Syn61 系列重编码 *E. coli* 为底盘，通过重新引入可将 TCG/TCA 解码为丙氨酸、组氨酸、亮氨酸或脯氨酸的嵌合 tRNA，建立 16 种重构遗传密码；将基因和可移动遗传元件改写为与特定解码器匹配的密码版本，建立正交及互正交 HGT 系统；再把重构密码“锁定”进受选择的必需功能，以阻断携带自身 tRNA 的质粒和噬菌体侵入。

论文的核心不是简单的“Syn61 抗病毒”，而是依次回答：

1. 仅做密码子压缩和 tRNA 删除为何仍是单向而非双向隔离；
2. 外来元件携带 tRNA 时如何突破隔离；
3. 重新分配 sense codon 如何创造互不兼容的代码—解码器对；
4. 与代码匹配的移动元件能否只在匹配宿主间传播；
5. 把重构密码绑定到必需基因后，能否进一步阻断携带竞争解码器的入侵。

# 三、研究问题和总体设计

## 科学问题

能否通过改变 sense codon 与天然氨基酸的对应关系，建立只允许相同代码系统之间交换遗传信息、同时阻止不同代码系统之间基因流动的双向遗传隔离？

## 核心假设

1. 仅删除 TCG/TCA 解码 tRNA 可阻止规范编码元件进入，但压缩编码的合成基因仍可被规范系统读取，因此隔离是非正交/单向的。
2. 外来移动元件携带缺失 tRNA 时可突破这种隔离。
3. 将 TCG/TCA 改配为其他天然氨基酸，可使同一基因在匹配解码器中正确翻译、在不匹配系统中错译。
4. 把移动元件的必需基因改写成特定正交代码，可限制其只在匹配宿主中传播。
5. 把正交代码嵌入受选择的宿主必需功能，可使竞争 tRNA 的进入同时破坏宿主必需蛋白翻译，从而增强入侵阻断。

## 总体实验链

`验证压缩代码非正交` → `观察携带 tRNA 的 F 元件逃逸` → `筛选/验证嵌合 tRNA` → `建立 16 种重构代码` → `构建正交基因` → `构建 O-F 移动元件` → `验证正交与互正交 HGT` → `将代码锁定到必需选择功能` → `挑战 F(WT+serT) 与携带 tRNA 的 phage 06/12`

# 四、实验实例级抽取

## EXP-01：规范编码与压缩编码抗性基因的可读性

- 宿主：
  - Syn61 WT（规范解码比较体系）；
  - Syn61Δ3（缺少 TCG/TCA 解码 tRNA）。
- 构建：
  - SpecR WT；
  - recSpecR (ΔTCG, TCA)。
- 条件：有/无 spectinomycin，琼脂平板过夜培养。
- 读出：抗生素条件下生长表示 SpecR 构建有功能。
- 观察：
  - SpecR WT 在规范解码体系中有功能，在 Syn61Δ3 中无功能；
  - recSpecR 在两种体系中均有功能。
- 结论：压缩代码是规范代码的子集，因此仅压缩并删除 tRNA 不构成双向正交。
- 补充验证：hygromycin resistance 构建见 fig. S1。

## EXP-02：F(WT) 接合与稀有逃逸事件

- donor：能读取规范密码并携带 F(WT) 的细胞；精确菌株需 data file S1。
- recipient：
  - 规范解码细胞；
  - Syn61Δ3；
  - 稀有事件实验为 Syn61Δ2。
- 观察：
  - F(WT) 可高效进入规范解码细胞；
  - 主实验未观察到其进入 Syn61Δ3；
  - 对 Syn61Δ2 强选择时获得 2 个可存活转接合克隆，频率相对规范接合约低 10^6 倍。
- 两个克隆测序显示获得了来自 donor、含 `serT` 的序列。
- 证据边界：
  - 这是 2 个独立克隆，不是 2 个生物学重复；
  - `10^6-fold less` 需保留分母和比较体系，不能改写成固定绝对概率；
  - 只支持所测选择体系下存在 tRNA 获取型逃逸路径。

## EXP-03：F(WT+serT) 可重复突破 tRNA 删除屏障

- 构建：在 F(WT) 上加入 `serT`。
- recipient：Syn61Δ3。
- 比较：F(WT) 对 F(WT+serT)。
- 读出：约 10^6 recipient/donor 尺度下的转接合菌落计数；确切分母以图注/补充方法为准。
- 观察：F(WT+serT) 可进入 Syn61Δ3，且该转移依赖 `serT`。
- 结论：获取缺失解码器足以绕过仅由代码压缩+tRNA 删除提供的隔离。

## EXP-04：嵌合 tRNA 筛选和密码子—氨基酸身份验证

- 宿主：Syn61Δ3。
- 候选 tRNA：将 CGA 或 UGA anticodon 引入 Ala、His、Leu、Pro isoacceptor tRNA。
- 报告体系：
  - sfGFP 第 3 位含 TCG 或 TCA；
  - ubiquitin 第 11 位含目标密码子。
- 读出：蛋白产量与 ESI-MS。
- 结果：多数嵌合 tRNA 优先读取 Watson-Crick 匹配密码子，并掺入其亲本 isoacceptor 对应氨基酸。
- 例外：`tRNA_UGA^Leu` fidelity 低于其他 tRNA。
- 来源：
  - Ala/Leu 候选由 aaRS identity-element 逻辑选择；
  - His/Pro 等还涉及筛选，详见 fig. S14。
- 不能把“特异”解释为绝对无近缘密码子读取；具体 fidelity 依赖 data file S3。

## EXP-05：建立 16 种重构遗传密码

- 变量：
  - TCG 可分配给 Ala/His/Leu/Pro；
  - TCA 可独立分配给 Ala/His/Leu/Pro。
- 组合：4×4=16。
- 直接验证层级：
  - Fig. 2 展示代码组合与代表性质谱；
  - 完整期望/实测质量见 data file S2；
  - fidelity 与交叉读取见 data file S3、figs. S3–S7；
  - 生长见 fig. S15。
- 论文称“大多数重分配菌株与亲本生长相当”，不能改写为 16 株全部无生长代价。

## EXP-06：构建正交抗性基因 O-SpecR

- 起点：recSpecR (ΔTCG, TCA)。
- 设计：
  - 27 个 GCN（Ala）→TCG；
  - 6 个 CAT/C（His）→TCA。
- 产物：O-SpecR (TCG-Ala, TCA-His)。
- 比较体系：
  - Syn61Δ3(tRNA_CGA^Ala, tRNA_UGA^His)；
  - Syn61 WT；
  - SpecR WT 对照。
- 观察：
  - O-SpecR 只在匹配 Ala/His 解码器中赋予 spectinomycin resistance；
  - 在规范解码体系中不赋予抗性；
  - SpecR WT 在 Ala/His 解码器中不赋予抗性。
- 结论范围：证明所测基因、编码密度、解码器和抗生素条件下的功能双向正交；不等于所有天然/合成基因天然具有相同隔离强度。

## EXP-07：O-F1 正交水平转移

- O-F1 构建：
  - 所有注释 ORF 先按 Syn61 规则压缩；
  - 移动元件复制必需基因 `trfA` 中 GCN→TCG、CAT/C→TCA。
- donor 元件：F(WT) 或 O-F1。
- recipient：
  - Syn61 WT；
  - Syn61Δ3(tRNA_CGA^Ala, tRNA_UGA^His)。
- 观察矩阵：

| 移动元件 | 规范解码 recipient | Ala/His 正交 recipient |
|---|---:|---:|
| F(WT) | 可转移 | 未观察到转移 |
| O-F1 | 未观察到转移 | 可转移 |

- 读出：约 10^6 donor cells 对应的转接合菌落数。
- “未观察到”必须绑定检测下限，不能写成数学上的零转移概率。

## EXP-08：五套互正交 HGT 系统

- 作者进一步建立其他代码—移动元件配对。
- Fig. 4C 用热图展示不同 recipient decoder 与 mobile element 的转接合菌落。
- 论文总结获得 5 个互正交 HGT 系统。
- 当前主 PDF 不足以完整重建五个系统的：
  - tRNA 对；
  - 代码规则；
  - 移动元件名称；
  - 全部交叉组合；
  - 检测下限和重复。
- 必须建立“移动元件 × recipient decoder”的验证矩阵；未提供 fig. S17/data S5 时不得声称全部 25 个交叉方向均在同一深度验证。

## EXP-09：无选择压力时对 F(WT+serT) 的部分阻断

- recipient：Syn61Δ3，含 Ala/His 解码 tRNA 及 O-SpecR。
- invading element：F(WT+serT)。
- 无 spectinomycin。
- 观察：转移约降低 10^4 倍，但未完全消除。
- 作者机制：宿主 Ala/His tRNA 与外来 `tRNA_UGA^Ser` 竞争，使 F 元件必需蛋白发生混合解码/错译。
- 证据等级：
  - 10^4 倍阻断为直接观察；
  - 特定位点随机竞争和必需蛋白错译是作者机制模型，图 5A/B 标为 predicted。

## EXP-10：code locking 对 F(WT+serT) 的阻断

- recipient：与 EXP-09 相同的重构代码宿主。
- 锁定方式：加入 spectinomycin，使正确读取 O-SpecR 成为细胞存活必需条件，从而使 TCG→Ala、TCA→His 解码规则在选择下不可被竞争 tRNA 轻易替代。
- 观察：在所测条件和检测限内未获得 F(WT+serT) 转接合子，论文称 `completely ablated`。
- 限定：
  - 是抗生素依赖的实验性 code lock；
  - 不证明撤除选择压力后的长期稳定；
  - 不证明所有外来移动元件均无法适应；
  - 其他代码/必需基因主要见 figs. S18、S19。

## EXP-11：携带 tRNA 的环境噬菌体挑战

- 来源：River Cam 噬菌体池。
- 分离物：phage 06、phage 12，均为 T4-like phage，携带相同 `tRNA_UGA^Ser`。
- 对照宿主：Syn61Δ3，可被 06/12 感染。
- 测试宿主：数个 refactored, code-locked strains；精确组合需 fig. S22。
- 感染输入：
  - phage 12：1.1×10^10 PFU/ml；
  - phage 06：7.5×10^9 PFU/ml。
- 条件：所有 Fig. 5D 实验均有 spectinomycin。
- 读出：形成 plaque 的成功复制噬菌体数量。
- 观察：在所测 code-locked strains 和检测条件下未观察到可复制噬菌体，论文称完全抗性。
- 长期共培养、噬菌体适应进化、其他 MOI/环境或更多病毒未测试。

## 1. `WT` 多义词典

| 原文标签 | 对象类型 | 正确含义 | 禁止解释 |
|---|---|---|---|
| Syn61 WT | 菌株/解码体系 | Syn61 家族中的规范解码比较体系 | 天然野生分离株 |
| SpecR WT | 基因构建 | 以规范密码编码的抗性基因 | WT 菌株 |
| F(WT) | 移动元件 | 以规范密码编码的 F 元件 | 未工程化宿主 |
| canonical (WT) decoding | 解码规则 | TCG/TCA→Ser 的规范解码 | 某个具体菌株基因型 |

## 2. 双向隔离必须拆成两个方向

```json
{
  "inward_isolation": {
    "direction": "canonical mobile element -> refactored host",
    "examples": ["F(WT)", "F(WT+serT)", "phage 06", "phage 12"]
  },
  "outward_isolation": {
    "direction": "orthogonally encoded mobile element -> canonical host",
    "example": "O-F1"
  }
}
```

不能仅因一个方向被阻断就声称“双向隔离”。本文通过 F(WT) 与 O-F1 的交叉 recipient 矩阵提供两个方向的功能证据。

## 3. `orthogonal` 与 `mutually orthogonal`

- orthogonal：某 O-F/decoder 对相对规范系统不兼容。
- mutually orthogonal：多个 O-F/decoder 对之间也彼此不兼容。
- “五套系统”是系统级数量；具体交叉验证覆盖率需验证矩阵。

## 4. “完全阻断/完全抗性”

结构化输出使用：

```json
  "detection_limit": "requires raw counts and supplementary methods",
  "selection_condition": "spectinomycin present",
  "long_term_escape_tested": false
}
```

## 5. 预测机制与直接观察

Fig. 1C/D、Fig. 3A、Fig. 4A、Fig. 5A/B 含预测性的翻译/HGT示意。示意图中的 “predicted to attenuate” 不得升级为逐分子测得的随机错译率。直接观察是菌落、抗性、质谱或 plaque 读出。

# 七、重复、样本与检测限

主 PDF 对许多主图未直接给出明确重复数。当前只能可靠记录：

- 接合读出是从约 `10^6` donor 或 recipient cells 规模得到的转接合菌落数；这不是重复数。
- 稀有逃逸实验获得 2 个克隆；这是独立克隆数，不是实验重复数。
- ESI-MS 图是产物身份读出；主 PDF 未明确每一组合的独立质谱重复数。
- plaque count 的输入以 PFU/ml 给出；PFU/ml 是噬菌体浓度，不是 MOI，也不是重复数。
