# 三、是否存在幻觉

## 明确存在，而且不是轻微幻觉

### 1. 虚构 `wt` 野生型对照

**结论：明确幻觉。**

### 2. 虚构统一的 control 组

### 3. 将制造温度作为培养条件

1250 °C、1300 °C 等为烧结工艺，不是培养温度。

**结论：严重语义幻觉。**

### 4. 将 glycerol 作为 carbon source

这里主要是 water-glycerol binder。

**结论：明确字段语义幻觉。**

### 5. 将多篇论文的参数拼成本文实验方案

每个数值多数在原文中真实出现，所以这不是“凭空创造数值”；但它发生了更危险的：

> **来源存在，但归属和语义错误。**

这属于**证据支持型幻觉**或**错误归因幻觉**：

* 证据片段真实；
* 字段归属错误；
* 来源研究层级错误；
* 最终形成论文不存在的实验设计。

这种幻觉比完全无出处的数值更难发现，因为每个值都可以在原文中搜到。

# 六、系统为什么会失败

从结果看，至少有六个架构问题。

## 1. 缺少论文类型分类器

系统在实验设计抽取前应先判断：

* original research；
* review；
* systematic review；
* meta-analysis；
* protocol；
* methods paper；
* case report；
* perspective/commentary。

本篇首页已经明确写着 `Research review paper`，仍未触发路由。

## 2. Schema 强制套用合成生物学/湿实验字段

当前字段明显偏向：

* strain；
* genotype；
* engineering_method；
* medium；
* carbon_source；
* OD；
* experimental groups。

面对材料科学综述时，规则只能通过关键词强行填充，最终产生灾难性误判。

## 3. 关键词规则缺少上下文语义

典型例子：

* `wt.%` → `wt`
* `duplicate search` → technical replicate
* `glycerol binder` → carbon source
* `1250 °C sintering` → culture temperature
* `500 μm scale/pore size` → dosage
* `1980s` → time duration

## 4. 缺少“研究层级”隔离

综述论文中至少有三种主体：

1. 本综述作者；
2. 被纳入研究；
3. 被引用的背景文献。

目前系统把三者全部扁平化成“本文实验”。

## 5. 表格行关系丢失

表 1 中每一行对应一个独立研究：

* powder；
* binder；
* layer thickness；
* saturation；
* depowdering；
* post-processing；
* sintering；
* further treatment；
* reference。

系统却把每一列的所有值分别合并成数组，破坏了行间关系。

结果是无法知道：

* 哪个温度属于哪个材料；
* 哪个时间对应哪个处理；
* 哪个孔径对应哪个研究；
* 哪个结果对应哪个对照。

## 6. QC 发现错误却未阻断输出

`result.json` 内部已经记录某些值 `supported: false`，但最终字段仍被标成：

* `status: reported`
* `confidence: 0.9`



说明 Evidence QC 没有真正成为硬门控。

# 七、建议怎样修改模块

## 必须增加的第一个 Gate：论文类型路由

建议在实验设计抽取前加入：

```text
ArticleTypeGate
```

输出至少包括：

```json
{
  "article_type": "review_article",
  "is_primary_experimental_study": false,
  "contains_original_experiment": false,
  "recommended_extraction_schema": "review_synthesis_schema",
  "confidence": 0.99,
  "evidence": [
    "Title page: Research review paper",
    "Material and methods describes literature search and study selection"
  ]
}
```

当 `is_primary_experimental_study = false` 时：

* 禁止进入原始实验抽取 Schema；
* 禁止输出 strain、genotype、culture_conditions 等论文级实验字段；
* 改走综述抽取器。

## 综述论文应采用独立 Schema

建议至少包括：

```json
{
  "review_objective": null,
  "review_questions": [],
  "database_sources": [],
  "search_strategy": [],
  "date_range": {},
  "language_restrictions": [],
  "inclusion_criteria": [],
  "exclusion_criteria": [],
  "screening_process": {},
  "data_extraction_process": {},
  "synthesis_method": null,
  "technology_categories": [],
  "evidence_summary": [],
  "limitations": [],
  "research_gaps": [],
  "conclusions": []
}
```

## 被综述研究要按 Study 分开

例如：

```json
{
  "cited_study": "Tarafder et al. 2013a",
  "study_type": "in_vitro_and_in_vivo",
  "material": "beta-TCP",
  "manufacturing": {
    "layer_thickness": "20 μm",
    "hardening": "175 °C for 90 min",
    "sintering_conditions": [
      "1150 °C conventional furnace for 2 h",
      "1250 °C conventional furnace for 2 h",
      "1150 °C microwave furnace for 1 h",
      "1250 °C microwave furnace for 1 h"
    ]
  },
  "outcomes": [],
  "source_level": "secondary_report_in_review"
}
```

不能将所有研究展平到一个总数组里。

## 必须加入缩写消歧规则

至少加入：

```text
wt.% / wt% / weight percent ≠ WT / wild type
```

并利用领域上下文判断：

* 材料科学中 `wt.%` 默认解释为质量百分比；
* 微生物学中孤立 `WT strain` 才可能表示野生型。

## 参数必须绑定语义角色

禁止只抽取数值与单位。

每个参数必须有：

```json
{
  "value": 1250,
  "unit": "°C",
  "parameter_type": "sintering_temperature",
  "process_step": "microwave_sintering",
  "material": "beta-TCP scaffold",
  "source_study": "Tarafder et al. 2013a"
}
```

无法确定角色时应标记 `unresolved_parameter`，而不是塞进最相近字段。

## QC 必须设置硬阻断

建议规则：

```text
若 evidence_validator.supported == false：
    不得标记 status=reported
    不得 confidence > 0.5
    不得进入 final_experimental_design
```

此外：

```text
若论文类型不是 primary experimental article：
    original_experimental_design = null
    route_to_article_specific_schema
```
