# 第四篇论文 Skill 回归测试

## 测试对象

- 论文：*Sense codon reassignment enables viral resistance and encoded polymer synthesis*
- DOI：10.1126/science.abg3029
- 文件：`03.pdf`
- 期刊与年份：*Science*，2021
- PDF：正文 6 页，另含 1 页文章信息
- 测试目标：验证全文菌株自主识别、组合删除株识别、进化代次隔离、`WT/wt` 语义消歧、实验实例绑定、重复类型、阶段性成功范围和补充材料硬门控。

## 总体结论

**PASS WITH MODERATE REVIEW：核心实验设计、菌株谱系和主要结果可可靠抽取；精确菌株重建、进化突变解释及实验 SOP 被缺失的 Supplementary Materials 硬阻断。**

这是原创实验研究。作者从已重编码的 *E. coli* Syn61 出发，先通过随机平行诱变和动态选择改善生长，再在同一菌株中组合删除 `serT`、`serU` 和 `prfA`，获得 Syn61Δ3；继续进化得到 Syn61Δ3(ev5)。随后分别验证：

1. 删除三个解码元件后的广谱噬菌体抗性；
2. TCG、TCA、TAG 的正交性及非天然氨基酸重分配；
3. 同一蛋白中两种或三种不同非天然氨基酸的编码掺入；
4. 完全由非天然单体组成的异聚物和大环产物的编码合成。

这篇论文不能被压缩成“Syn61 做了所有实验”。不同实验实际使用 Syn61(ev2)、Syn61ΔRF1、Syn61Δ3、Syn61Δ3(ev4) 或 Syn61Δ3(ev5)，必须逐项绑定。

# 三、研究问题与设计逻辑

## 生物学问题

从已移除 TCG、TCA、TAG 的细胞基因组中进一步删除相应解码元件，能否使这些密码子在细胞内不可读，并形成针对依赖宿主翻译系统的病毒的遗传防火墙？

## 工程问题

释放的三个密码子能否分别重新分配给非天然氨基酸，从而在同一细胞内编码多种不同单体，并进一步合成完全非天然的线性异聚物和大环产物？

## 总体链路

`Syn61` → `2 轮诱变/动态选择` → `Syn61(ev2)` → `同株组合删除 serT/serU/prfA` → `Syn61Δ3` → `3 轮诱变/动态选择` → `Syn61Δ3(ev5)` → `噬菌体抗性 + 密码子正交性` → `单/多种 ncAA 编码` → `非天然异聚物与大环合成`

注意：后续功能实验并非全部等待 ev5；Fig. 4 的双重和三重不同 ncAA 掺入使用 Syn61Δ3(ev4)。

# 四、实验实例级抽取

## EXP-01：删除前适应性进化

- 宿主：Syn61。
- 干预：随机平行诱变与自动动态平行选择，连续两轮。
- 选择逻辑：反馈控制根据生长率动态稀释突变培养物，富集快速生长群体。
- 产物：Syn61(ev1)、Syn61(ev2)。
- 结果：Syn61(ev2) 相比 Syn61 生长快 1.3 倍。
- 边界：`1.3-fold faster` 是作者的生长比较表达；具体计算、培养条件和统计见 fig. S1 与补充方法。

## EXP-02：构建三解码元件组合删除株

- 亲本：Syn61(ev2)。
- 操作：在同一菌株中删除 `serU`、`serT`、`prfA`。
- 产物：Syn61Δ3。
- 设计目的：直接测试三个删除之间的上位性及组合可行性。
- 结果：组合删除株可获得；其生长相对 Syn61(ev2) 下降。
- 定量表述：论文称 Syn61Δ3 “grew 1.7 times slower”，应保留作者措辞并优先以原始生长率/倍增时间数据表达；主文不足以安全换算成唯一数学比值。

## EXP-03：删除后恢复性进化

- 起点：Syn61Δ3。
- 干预：三轮顺序随机平行诱变和自动动态选择。
- 中间体：Syn61Δ3(ev3)、Syn61Δ3(ev4)。
- 终产物：Syn61Δ3(ev5)。
- 结果：作者报告 ev5 比 Syn61Δ3 生长快 1.6 倍；LB 摇瓶倍增时间为 38.72±1.02 min。
- 最终序列状态：相对 Syn61 有 482 个额外突变；目标密码子没有回复突变。
- 限定：16 个非必需基因中的 sense codons 被变为目标密码子（5×TCG、3×TCA、8×TAG），其功能含义和逐位清单需 data S1。

## EXP-04：T6 一步生长/总滴度实验

- 比较：Syn61(ev2)、Syn61ΔRF1、Syn61Δ3，并含无细胞及 gentamicin 抑制蛋白合成对照。
- 感染：T6，MOI = 5×10^-2。
- 读出：0–4 h 总噬菌体滴度（细胞内+游离 PFU）。
- 直接观察：
  - Syn61(ev2) 中 T6 滴度先降后升至输入水平上方约两个数量级；
  - Syn61ΔRF1 与 Syn61(ev2) 相近；
  - Syn61Δ3 中滴度持续下降，接近 gentamicin 对照。
- 重复：3 个独立重复。
- 解释边界：支持三解码元件组合删除阻止所测条件下 T6 的新粒子产生；不等于证明所有病毒绝对无法适应。

## EXP-05：T6/T7 裂解与混合噬菌体挑战

- T6 裂解：按 EXP-04 条件感染，4 h 测 OD600。
- T7：正文报告获得相似结果，细节位于 fig. S3。
- cocktail：λ、P1vir、T4、T6、T7，各自 MOI = 1×10^-2。
- 比较：Syn61(ev2)、Syn61ΔRF1、Syn61Δ3；有感染与无感染。
- 读出：0/4 h 培养物外观及 4 h OD600。
- 重复：3 个独立重复；照片为其中一个代表。
- 结论：Syn61Δ3 对所测噬菌体组合表现出强抗性。
- 禁止泛化：“complete resistance”只在论文测试的病毒集合、MOI、培养条件和时间窗内成立。

## EXP-06：三个目标密码子的单独正交性与重分配

- 宿主：正文写后续实验使用 Syn61Δ3 或可用时使用其进化衍生株；Fig. 3 的正文实验明确为 Syn61Δ3(ev5)。
- 报告基因：Ub11XXX，其中 XXX 分别为 TCG、TCA、TAG；`wt Ub` 不含目标密码子。
- 翻译系统：对应 anticodon 的 MmPylRS/MmtRNAPyl 对。
- 条件：有/无 BocK。
- 读出：抗 His6 Western blot、ESI-MS/MS。
- 结果：
  - 无 ncAA 时目标密码子报告基因几乎不产生全长 ubiquitin；
  - 加 BocK 后恢复接近 wt reporter 的表达；
  - 质谱确认 BocK 在目标位置掺入。
- 子实验必须按 TCG/CGA、TCA/UGA、TAG/CUA 三组分别保存。
- 重复：Fig. 3 全部实验为 3 次生物学重复且结果相似。

## EXP-07：同种 ncAA 的多位点掺入

- 报告基因分别含 1、2、3、4 个相同目标密码子位点。
- 每种目标密码子 TCG、TCA、TAG 独立测试。
- 另有单一蛋白中 9 个 TCG 位点的补充实验。
- 读出：Western blot 与 ESI-MS。
- 结论限定：支持所测试蛋白、位点数和表达条件下的多位点编码，不等于任意蛋白或任意位点都同样高效。

## EXP-08：两种不同 ncAA 的同时编码

- 宿主：Syn61Δ3(ev4)。
- 密码子：TCG 与 TAG。
- 系统：
  - TCG/CGA → CbzK；
  - TAG/CUA → p-I-Phe。
- 构建：Ub11TCG,65TAG；以及含 2×TCG/2×TAG 的四位点构建。
- 对照：wt Ub、有/无两种 ncAA。
- 读出：Western blot、纯化产物 ESI-MS。
- Western blot：5 个生物学重复，结果相似。
- ESI-MS：采集 1 次。
- 质谱单次验证不得与 Western blot 的 5 个生物学重复合并。

## EXP-09：三种不同 ncAA 的同时编码

- 宿主：Syn61Δ3(ev4)。
- 密码子分配：
  - TCG → CbzK；
  - TCA → BocK；
  - TAG → p-I-Phe。
- 报告基因：Ub9TAG,11TCG,14TCA。
- 对照：有/无三种 ncAA。
- 读出：Western blot 与 ESI-MS。
- 重复：Western blot 5 个生物学重复；ESI-MS 1 次。
- 补充材料还报告 7 个不同的三 ncAA ubiquitin 版本；不能仅凭正文重建全部组合。

## EXP-10：非天然异聚物编码规则验证

- 编码思想：对单体 A/B，测试 AA、AB、BA、BB 四种基本肽键形成步骤。
- DNA：在 sfGFP 第 3 位插入 TCG-TCG、TCG-TAG、TAG-TCG、TAG-TAG。
- 三组重分配体系：
  - BocK / p-I-Phe；
  - CbzK / p-I-Phe；
  - AllocK / CbzK。
- 依赖性对照：只有同时加入相应两种 ncAA 才产生目标表达。
- 论文报告：每组编码 6 种完全非天然四聚体和 1 种六聚体，AllocK/CbzK 另编码八聚体；总计 22 个合成聚合物序列。
- 阶段区分：
  - 报告基因表达成功；
  - sfGFP 融合产物质谱确认；
  - 不能把“22 个编码构建”自动等同于“22 个均被同等强度质谱确认”。
- Fig. 5F 的 ESI-MS 数据采集 1 次。

## EXP-11：游离聚合物和大环产物

- 宿主：Syn61Δ3(ev5)。
- 构建：非天然四聚体/六聚体位于 SUMO 与 GyrA-CBD 之间。
- 释放：
  - Ulp1 cleavage；
  - GyrA transthioesterification cleavage。
- 大环：在聚合物上游加入额外 cysteine，触发自切割并释放大环非天然聚合物。
- 读出：纯化产物 ESI-MS。
- 结论：支持展示的 AllocK/CbzK 线性与大环产物；不能扩展为所有 22 个序列均形成游离大环。

# 五、关键语义与范围审计

## 1. 单独删除与组合删除

- 前序论文：`serT`、`serU`、`prfA` 分别删除。
- 本论文：在 Syn61(ev2) 的同一衍生株中组合删除，得到 Syn61Δ3。

因此：

```json
{
  "previous_separate_deletions": "background_citation",
  "current_combined_deletion": "directly_reported_current_article",
  "combined_genotype": "Syn61(ev2) ΔserT ΔserU ΔprfA"
}
```

## 2. 进化轮次不是实验重复

- `ev1`–`ev5` 是累计进化阶段。
- Fig. 1 生长曲线的 `n=8 replicate cultures` 才是重复培养。
- 主文未在该句明确称其为 biological replicates，故保留 `replicate_cultures`，不擅自升级。

## 3. “完全病毒抗性”的限定域

`complete resistance` 是作者对实验集合的总结。结构化输出必须附：

```json
{
  "tested_viruses": ["T6", "T7", "lambda", "P1vir", "T4"],
  "cocktail_MOI_each": "1e-2",
  "single_T6_MOI": "5e-2",
  "observation_window_h": 4,
  "excluded_generalizations": [
    "all possible viruses",
    "all infection conditions",
    "evolutionary impossibility of viral escape"
  ]
}
```

## 4. “所有目标密码子正交”的限定域

该结论由特定 ubiquitin/GST-MBP/repeat-protein 构建及翻译系统支持。它不自动证明：

- 所有基因上下文均零背景读取；
- 所有生长阶段完全相同；
- 所有正交 aaRS/tRNA 对无交叉反应；
- 长期进化中不会恢复解码。

## 5. “22 条聚合物序列”与验证层级

设计/表达、融合产物质谱、游离聚合物纯化和大环形成属于不同阶段。输出不得把总编码序列数复制成每个下游验证阶段的成功数。

## 6. 生长倍数

论文使用 `1.3-fold faster`、`1.7 times slower`、`1.6-fold faster`。在缺少补充数据时：

- 保留作者原始表达；
- 同时记录对应比较对象；
- 不把生长率倍数转换为倍增时间倍数；
- 仅对明确给出的 38.72±1.02 min 建立倍增时间字段。
