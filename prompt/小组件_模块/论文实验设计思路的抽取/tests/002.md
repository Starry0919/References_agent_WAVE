# 一、我独立重建出的论文实验设计

## 1. 核心科学问题

作者面对的问题是：

* 复杂工业表型通常涉及大量基因和调控关系；
* 单基因逐步修改或随机进化只能覆盖很小的组合空间；
* 需要一种可以系统扰动全局调控网络、同时能够追踪每个突变的方法。

因此，作者提出的总体策略是：

> 选择大量全局或高层级调控蛋白，对其功能区域进行高密度饱和突变，通过 CREATE 将预设计突变写入基因组，再以不同工业表型进行选择，并利用编辑盒条形码测序建立基因型—表型关系。

论文设计、构建并映射了含 **82 个调控因子、110,120 个特定突变**的文库。

---

## 2. 实验设计的真正主线

### 阶段一：确定调控因子及功能位点

作者从多个数据库和既往研究中选择调控因子及目标区域：

* NCBI；
* EcoCyc；
* RegulonDB；
* UniProt；
* PDB；
* Pfam；
* 既往定向进化研究。

靶向区域包括：

* DNA-binding sites；
* ligand-binding sites；
* protein-interface sites；
* dimerization interfaces；
* 预测蛋白结构域。

对于有 PDB 结构的蛋白，作者重点选择距结合区域或二聚界面小于 5 Å 的位点；Pfam 结构域采用高于 90% 的后验概率。

### 阶段二：设计调控网络饱和突变文库

* 82 个调控蛋白；
* 约关联 4000 个基因；
* 共 110,120 个预设计突变；
* 每个编辑盒带有可测序追踪的设计信息；
* 文库分为四个子文库。

这里的设计重点不是随机诱变，而是：

> **预先定义目标位点和替换，再通过 barcode/editing cassette 将选择结果映射回具体突变。**

### 阶段三：构建质粒文库

主要流程：

1. 扩增 pooled oligos；
2. 扩增并 DpnI 处理质粒骨架；
3. 使用 CPEC 组装；
4. 将组装产物电转入 `E. cloni 10G ELITE`；
5. 在含 carbenicillin 的 LB 中扩增；
6. 提取质粒文库。

`E. cloni 10G ELITE` 在这里是**质粒克隆和扩增宿主**，不是后续复杂表型筛选的实验底盘。

### 阶段四：在 MG1655 中建立基因组编辑文库

目标宿主为：

* `E. coli MG1655`
* 携带 `pSIM5`
* 携带 `pX2-Cas9`

关键操作：

1. 培养至 OD600 0.5–0.6；
2. 42 °C 振荡诱导 pSIM5 15 min；
3. 冰上放置 15–30 min；
4. 冰冷 ddH₂O 洗涤；
5. 与文库质粒混合；
6. 电转；
7. SOB 恢复 2 h；
8. 转入含 kanamycin 和 carbenicillin 的 LB；
9. 每个子文库随机测序 50 个克隆评价编辑效率和多样性。

结果：

* 编辑效率约 30%–85%；
* 突变多样性约 30%–74%。

论文将部分效率损失归因于 oligo 合成和质粒构建过程中 spacer 区域错误削弱 gRNA 活性。

### 阶段五：多表型选择

对文库分别施加：

| 表型      |                 条件 |
| ------- | -----------------: |
| 糠醛耐受    |     2 g/L furfural |
| 苯乙烯耐受   |   300 mg/L styrene |
| 乙酸利用/生长 |     30 g/L acetate |
| 异丙醇耐受   | 30 g/L isopropanol |
| 异丁醇耐受   |   8 g/L isobutanol |

共同选择流程：

* 初始 OD600 = 0.1；
* 在锥形管或摇瓶中培养；
* 根据生长速度，在 48–96 h 内进行两次 serial dilution；
* 选择后收集群体；
* 扩增并测序 barcode-editing cassette；
* 计算选择前后突变频率变化。

特别需要注意：

> 论文摘要与讨论中的“single round of selection”不能机械解释成只培养一次或只传代一次。Methods 明确写了两次 serial dilutions。这里更接近“一次文库筛选流程即可找到候选突变”，而不是“一次培养步骤”。

### 阶段六：候选突变重构和耐受验证

作者将富集突变单独重构回相应宿主，并与 `nontargeting control` 比较。

代表性重构包括：

* 糠醛：`soxR_I120A`、`rpoC_Q623R`、`rpoB_E546C`、`marR_K81T`；
* 苯乙烯：`CsgD_L180F`、`fliA_E215V`、`lexA_L35M`、`narP_S170E`；
* 乙酸：`soxR_V23Y`、`rpoS_E289T`、`cytR_L17Q`、`phoB_R213G`。

图 1 中这些重构变体在相应选择压力下与 nontargeting control 进行比较，每条曲线 `n = 3`。

### 阶段七：C3–C4 醇耐受与生产验证

异丙醇和异丁醇选择中，作者发现部分共同富集基因和突变，例如：

* `fis`
* `fur`
* `FliA_R94K`
* `RpoE_D182Y`

重构后的部分变体在两种醇胁迫下表现更好；作者随后把候选突变引入具有整合生产通路的菌株：

* `PA14`：异丙醇生产背景；
* `IB500C`：异丁醇生产背景。

`FliA_R94K` 在这两个生产背景中使醇产量约提高 50%，但完整生产株基因型需要补充材料才能重建。

### 阶段八：FliA_R94K 机制研究

对 `FliA_R94K` 与 nontargeting control 进行转录组比较。

主要观察：

* 醇胁迫下超过 1000 个基因变化超过 2 倍；
* `fliA` 表达显著升高；
* 多个细胞膜、细胞壁、能量代谢和应激相关基因发生变化；
* ATP 浓度在醇胁迫下约提高 3 倍；
* 无胁迫和有异丁醇胁迫下的转录响应明显不同。

这支持 `FliA_R94K` 的作用具有较强环境依赖性，但部分机制语言仍是作者基于转录相关性的解释，不应全部升级为已经验证的直接因果链。

### 阶段九：异丁醇生物传感器选择

作者使用：

* `IB500C ΔadhE`
* `pSelect-1`
* `PBMO` 调控的 `tetA-gfp`

将异丁醇存在与：

* TetA 介导的生长优势；
* GFP 信号；

关联起来，在 96 孔板中选择异丁醇高生产变体。

随后：

* 测序富集突变；
* 重构 12 个候选变体；
* 测量异丁醇产量；
* 进一步进行发酵验证。

### 阶段十：OmpR 与 RstA 分析

异丁醇生产选择中，`ompR` 多个突变富集。

其中：

* `OmpR_S181K` fed-batch 约产生 10.6 g/L 异丁醇；
* 约为 nontargeting control 的 1.4 倍。

图 4 中：

* 48 h 生产比较明确是三个 biological replicates；
* fed-batch 曲线为 `n = 3`。

作者还比较了 `rstA` 在异丁醇耐受和生产选择中的位点分布：

* 生产相关突变偏向 receiver domain；
* 耐受相关突变偏向 DNA-binding domain。

但 D52、E8、Y98 等位点如何影响磷酸化，多数属于结构基础上的机制推测，并非全部得到直接生化验证。

# 三、需要修订或人工审核的部分

## 1. 富集分数公式没有处理论文内部的不一致

这是本篇最值得人工审核的问题。

论文 Methods 的文字说：

> enrichment scores were calculated as the logarithm (base 2) of the ratio of post-selection frequency to preselection frequency.

这通常意味着：

[
E_j=\log_2\left(\frac{Y_j}{X_j}\right)
]

但 PDF 中排版出的公式看起来是：

[
E_j=\frac{\log_2(Y_j)}{\log_2(X_j)}
]

两者在数学上完全不同。PDF/全文解析均呈现为后者。

`02.md` 只写了“选择后/选择前频率比的富集分数”，没有指出正文文字与公式排版之间的冲突。

### 判断

这不一定是 Skill 幻觉，更可能是原论文排版、文本抽取或公式转换问题。但对于严格复现实验，这是必须人工确认的。

### 建议

应标记：

```json
{
  "status": "source_internal_inconsistency",
  "prose_interpretation": "log2(Yj/Xj)",
  "displayed_equation": "log2(Yj)/log2(Xj)",
  "requires_manual_review": true
}
```

最好进一步核查：

* 原始 HTML/MathML；
* 作者代码；
* Source Data；
* CREATE 相关前序论文的方法。

### 严重度

**S3：严重复现风险**

它不改变整篇实验思想，但会直接影响所有富集分数重算。

## 2. “单轮选择”表达仍需更严谨

Skill 的目标描述中保留了“单轮选择中发现突变”，与摘要一致。

但 Methods 明确说明：

* 每次选择包含两次 serial dilutions；
* 整体持续 48–96 h。

因此，不能让前端用户理解为：

* 不传代；
* 单次培养；
* 单个时间点；
* 一步完成。

更准确的表达是：

> 在一次选择实验流程或一次筛选 campaign 中，通过两次连续稀释富集即可获得候选突变，无需多轮独立 ALE 周期。

## 4. “wild-type/background strain comparison”不宜作为通用对照

`02.md` 将对照总结为：

* 具体实验中的 wild-type/background strain；

| 单突变生长验证 | nontargeting control                |
| 转录组     | FliA_R94K vs nontargeting control   |
| OmpR 发酵 | OmpR mutant vs nontargeting control |

**S1–S2**

## 5. 显著性判断的描述有潜在统计过度简化

Skill 写：

> 以约 μ ± 2σ 判定显著富集；报告为近似 P ≤ 0.05。

这忠实反映论文 Methods。论文确实声称利用同义突变分布、20,000 次 bootstrap，以及 `μ ± 2σ` 进行判断。

但需要注意：

* bootstrap 95% CI；
* `μ ± 2σ`；
* 假定正态分布下 P≤0.05；

三者不是完全同一统计概念。

Skill 不应进一步把它解释成严格的标准假设检验或校正后的 P 值。

建议输出：

```text
authors' significance heuristic
```

而不是泛化成通用统计显著性分析。

### 严重度

**S2：统计解释风险**

## 7. FliA 和 OmpR 的机制表述应加强“推断”标签

Skill 写：

* FliA_R94K 通过应激响应和 ATP 代谢变化改善醇耐受；
* OmpR 突变使更多代谢通量进入异丁醇；
* pykA、pdhR 等转录变化支持 pyruvate 积累。

这些总体符合论文讨论，但其中大量句式是：

* likely；
* could；
* suggested；
* might。

例如：

* 上调的膜相关基因“could improve”稳定性；
* pykA/pdhR 变化“suggested”更多通量流向异丁醇；
* D52 等突变“likely affect”RstA 磷酸化。

因此应分成：

* **直接观察**：基因表达变化、ATP 浓度变化、产量变化；
* **机制推断**：膜稳定性提高、通量增加、磷酸化受影响；
* **未直接验证**：具体转录因子—代谢通量因果链。

`02.md` 的总体描述较谨慎，但最终“机制和产量验证”容易让用户理解为机制已被完全验证。

### 严重度

**S2**
