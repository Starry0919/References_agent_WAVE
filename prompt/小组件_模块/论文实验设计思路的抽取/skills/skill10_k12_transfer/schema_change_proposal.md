# Unified schema change proposal

No framework schema was modified. The unified `k12TransferAnalysis` definition supports one analysis but not multi-paper objective clusters, standardized matrices, explicit fact/analysis separation, candidate design spaces, or validation lists.

A future schema version may optionally add these Skill10 extension collections. Until then, `k12_transfer_analyses` provides one valid unified-core object per literature design while the richer comparison object remains a Skill10 extension.
