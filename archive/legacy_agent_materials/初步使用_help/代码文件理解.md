# Agent-harness 项目结构理解

## 1. 整体架构

```text
用户
 ↓
web（前端交互）
 ↓
main.py（启动与初始化）
 ↓
harness（Agent运行框架）
 ↓
LLM + tools（推理与执行）
 ↓
workspace（数据处理）
 ↓
runs（运行记录）
```

---

# 2. 核心目录作用

| 文件/目录      | 作用                                               |
| ---------- | ------------------------------------------------ |
| main.py    | 项目入口，负责启动系统、初始化Agent、加载组件                        |
| harness/   | Agent核心框架，负责管理Agent循环：接收任务 → 调用LLM → 调用工具 → 返回结果 |
| tools/     | Agent可调用的具体工具，是Agent的“能力模块”                      |
| web/       | 前端页面，用于用户与Agent交互                                |
| workspace/ | Agent工作空间，存放输入文件、中间结果、生成文件等                      |
| runs/      | 保存Agent运行过程，方便调试、复现和分析                           |
| docs/      | 项目说明文档、开发文档等                                     |
| .venv/     | Python虚拟环境，存放项目依赖                                |
| README.md  | 项目介绍和使用说明                                        |

---

# 3. Tool 和 Skill 的区别

* **Tool：具体执行动作**

  * 例如：查询基因、读取文件、设计引物。
  * 对应 `tools/`。

* **Skill：完成某类任务的方法集合**

  * 例如：“基因敲除设计 Skill”。
  * 内部可以包含多个 Tool、Prompt 和 Workflow。

关系：

```text
Skill
 ↓
多个 Tool + Workflow + Rules
```

因此：

> tools 是 skills 的底层能力，不等于 skill。

# 4. 配置文件区别

## .env（运行环境配置）

作用：

保存程序运行时需要的参数。

例如：

```text
API key
调用模型名称
服务器地址
```

特点：

* 会影响程序运行
* 可以快速切换模型
* 通常不上传Git

---

## pyproject.toml（Python项目配置）

作用：

描述Python项目本身。

包括：

* 项目名称
* 版本
* 依赖
* 打包方式

不会直接运行，但会被Python工具读取。

例如：

```bash
pip install .
```

会读取它。

---

## requirements.txt（依赖列表）

作用：

记录项目需要安装的第三方Python库。

例如：

```text
openai
fastapi
requests
```

对应代码中的：

```python
import openai
```

注意：

Python自带库不用写。

---

## pyrightconfig.json

作用：

Python代码类型检查配置。

主要检查：

* 类型错误
* 参数错误

不是主要负责语法检查。

# 6. Agent运行流程

```text
用户输入
 ↓
web（前端）
 ↓
main.py（启动与转发）
 ↓
harness（Agent核心）
 ↓
LLM分析任务
 ↓
调用tools
 ↓
获得结果
 ↓
生成回答
 ↓
返回用户
```

核心机制：

> Agent通过“思考 → 调用工具 → 获取反馈 → 再思考”的循环完成任务。

---

# 7. harness内部文件作用

| 文件           | 作用                             |
| ------------ | ------------------------------ |
| agent.py     | Agent核心，负责任务理解、调用LLM、调用工具、生成结果 |
| llm.py       | 连接大模型（GPT、Claude、DeepSeek等）    |
| providers.py | 管理不同模型供应商                      |
| config.py    | 管理运行参数和配置                      |
| events.py    | 记录Agent运行事件                    |
| sessions.py  | 管理上下文和历史会话                     |
| server.py    | 提供接口，让网页或程序调用Agent             |
